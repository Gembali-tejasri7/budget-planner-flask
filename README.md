# Budget Planner Web Application

## Description
This project is a web-based budget planner that helps users track income, expenses, and savings.

## Technologies Used
- Python
- Flask
- HTML
- CSS

## Features
- Track income
- Manage expenses
- Set savings goals
- View financial summaries

## Project Structure
app.py  
templates/  
static/

## How to Run
1. Install Python
2. Install Flask
3. Run the command:
   python app.py
4. Open browser and go to:
   http://localhost:5000
